What is this?

When enabled, this extension acts as a local MCP (Model Context Protocol) server so coding agents like OpenCode or Claude Code can call this extension's tools (and tools of other MCP-aware extensions) securely on this machine.

Connect your agent

Point your agent to the Unix domain socket path below (see the FAQs page for integration details). Make sure to restart the agent after this feature is turned on.

To verify the integration, ask your agent to call open_page without arguments to open https://example.com in a new tab of this browser.

Requirements

The native client version 1.1.0 or higher is required (see the "Native Integration" tab). Also restart your agent after enabling this feature.

Native Integration

Checking the native client…
  1. Double-click the downloaded install.bat file
  2. Open a terminal in the extracted directory and run ./install.sh
The "native client" is a small open-source NodeJS-based helper that connects the browser to your external applications (required for running commands and for the MCP server). If a system NodeJS is detected, it will be used; otherwise the package ships a portable version. The MCP Server requires native client version 1.1.0 or higher. To install manually, browse all releases. To uninstall, run ./uninstall.shuninstall.bat from the extracted directory.

Use "Add new Trigger" button to create a new trigger

Triggers launch external applications on events like custom keyboard shortcuts, download start/finish, or a user JavaScript being executed on every page. Scripts need access to all websites; the browser asks for the permission when the "Run JavaScript" action is selected.
